# Kyvelon

Cube-structured digital studio site for **Kyvelon** — software, websites, automation, and digital services. Founded by [George Gad](https://georgegad.com) in Athens.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Brand palette from the Kyvelon logo: electric blue `#0038F8` and navy `#06102B`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4317](http://localhost:4317).

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Dev server on port 4317  |
| `npm run build`| Production build         |
| `npm run start`| Start production server  |
| `npm run lint` | ESLint                   |

## Concept

The site is built around **κύβος** (cube): hero 3D cube, four service faces, and a Structure → Faces → Assemble method.
