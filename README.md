# Kyvelon

Cube-structured digital studio site for **Kyvelon** — software, websites, automation, and digital services. Founded by [George Gad](https://georgegad.com) in Athens.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Brand palette from the Kyvelon logo: electric blue `#0038F8` and navy `#06102B`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4317](http://localhost:4317).

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Dev server on port 4317  |
| `npm run build`| Production build         |
| `npm run start`| Start production server  |
| `npm run lint` | ESLint                   |

## Concept

The site is built around **κύβος** (cube). The hero is a real interactive cube UX:

- Drag / touch to rotate
- Click a face (or use the face chips) to snap and jump to that section
- Active-face panel updates as you explore
- Six faces: Software, Websites, Automation, Services, Method, Contact

Below that: four service faces, Structure → Faces → Assemble method, founder, and contact.
